Arrays provide O(1) indexed access. Strings are immutable in Java, so use StringBuilder for repeated edits.

Imports for this page: import java.util.HashMap; and import java.util.Map;. Arrays and StringBuilder are available from java.lang and do not need imports.

When to use each pattern

Two pointers

Use for sorted arrays, comparing both ends, or in-place edits. Moving a pointer must have a reason: in a sorted pair-sum problem, move the left pointer to increase the sum and the right pointer to decrease it.

Sliding window

Use for contiguous subarrays or substrings. Define what is always true inside the window, then expand and shrink while preserving it.

Prefix sums

Use for many range-sum queries. Store cumulative totals so any range is the difference between two prefix values.

Java templates

Two pointers: pair sum

int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return true;
    if (sum < target) left++;
    else right--;
}
return false;

Time O(n) after sorting. The key invariant is that all pairs outside the current [left, right] range have already been ruled out. If sorting is needed, include its O(n log n) cost.

Sliding window: fixed-size maximum sum

int sum = 0;
for (int i = 0; i < nums.length; i++) {
    sum += nums[i];
    if (i >= k) sum -= nums[i - k];
    if (i >= k - 1) best = Math.max(best, sum);
}

Initialise best before this loop, usually to Integer.MIN_VALUE when negative values are possible. Invariant: once i ≥ k - 1, sum is the total of exactly k elements. Each value enters and leaves once, so time is O(n).

Prefix sum

int[] prefix = new int[nums.length + 1];
for (int i = 0; i < nums.length; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
}
int rangeSum = prefix[right + 1] - prefix[left];

prefix[0] represents the sum before the array starts, which removes special cases for ranges beginning at zero. Build in O(n); each inclusive range query is O(1).
