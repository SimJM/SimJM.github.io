Trees & graphs

Choose DFS for deep exploration and BFS when distance or levels matter.

A tree is a specialised graph. Learn to define the node, traversal order, visited state, and the information returned from each recursive call.

Imports for this page: import java.util.ArrayDeque;, import java.util.ArrayList;, import java.util.List;, and import java.util.Queue;. For tree questions, define TreeNode only when the platform does not provide it.

Choose a traversal

Depth-first search

Use for reachability, connected components, cycle detection, backtracking, and tree recursion. Recursive DFS uses call-stack space proportional to depth.

Breadth-first search

Use for shortest paths in an unweighted graph and level-order traversal. It explores vertices by distance layers.

Visited state

Graphs can contain cycles. Keep a boolean[] or HashSet of visited nodes, and mark nodes when you enqueue them in BFS.

Graph representations

Objects and pointers

class Node {
    int value;
    List<Node> neighbours = new ArrayList<>();
}

Natural when each node carries data or behaviour, and pointers make object relationships easy to follow. It uses O(V + E) space, but identity, equality, and traversal bookkeeping require care.

Adjacency list

List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) {
    graph.add(new ArrayList<>());
}
graph.get(from).add(to);
graph.get(to).add(from); // only if undirected

Stores only existing edges, so it uses O(V + E) space and is usually best for sparse graphs. Neighbour iteration is efficient; checking whether one specific edge exists may require scanning a list.

Adjacency matrix

boolean[][] graph = new boolean[n][n];
graph[from][to] = true;
graph[to][from] = true; // only if undirected

Uses O(V^2) space regardless of edge count. It gives O(1) edge lookup, but scanning neighbours costs O(V), so it fits dense graphs or problems with frequent edge-existence checks.

Java templates

DFS

void dfs(int node, List<List<Integer>> graph,
         boolean[] visited) {
    visited[node] = true;
    for (int neighbour : graph.get(node)) {
        if (!visited[neighbour]) {
            dfs(neighbour, graph, visited);
        }
    }
}

Time O(V + E). The recursive call means “visit everything reachable from this neighbour.” In a tree, you do not need a visited set if each node has one parent; in a graph, it prevents infinite loops.

BFS shortest path

Queue<Integer> queue = new ArrayDeque<>();
queue.offer(start);
visited[start] = true;
int distance = 0;

while (!queue.isEmpty()) {
    for (int size = queue.size(); size > 0; size--) {
        int node = queue.poll();
        if (node == target) return distance;
        for (int next : graph.get(node)) {
            if (!visited[next]) {
                visited[next] = true;
                queue.offer(next);
            }
        }
    }
    distance++;
}

The outer loop represents one distance layer. The first time BFS reaches the target is the fewest-edge path. Mark nodes visited when enqueuing them, otherwise several parents can add the same node.

Connectivity and cycles

Connectivity

For an undirected graph, start DFS or BFS from one vertex and count visited vertices. The graph is connected when every vertex is reached. To count connected components, repeat the traversal from each unvisited vertex.

For a directed graph, distinguish one-way reachability from strong connectivity: strong connectivity requires every vertex to reach every other vertex.

Cycle detection

boolean hasCycle(int node, int parent,
                 List<List<Integer>> graph,
                 boolean[] visited) {
    visited[node] = true;
    for (int next : graph.get(node)) {
        if (!visited[next] && hasCycle(next, node, graph, visited)) return true;
        if (visited[next] && next != parent) return true;
    }
    return false;
}

For an undirected graph, an already visited neighbour is a cycle unless it is the node's parent. For directed graphs, use three states: unvisited, visiting, and finished; an edge to a visiting node is a back edge and proves a cycle.
