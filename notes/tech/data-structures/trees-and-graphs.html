Choose DFS for deep exploration and BFS when distance or levels matter.

A tree is a specialised graph. Learn to define the node, traversal order, visited state, and the information returned from each recursive call.

Imports for this page: import java.util.ArrayDeque;, import java.util.ArrayList;, import java.util.List;, and import java.util.Queue;. For tree questions, define TreeNode only when the platform does not provide it.

Choose a traversal

Depth-first search

Use for reachability, connected components, cycle detection, backtracking, and tree recursion. Recursive DFS uses call-stack space proportional to depth.

Breadth-first search

Use for shortest paths in an unweighted graph and level-order traversal. It explores vertices by distance layers.

Visited state

Graphs can contain cycles. Keep a boolean[] or HashSet of visited nodes, and mark nodes when you enqueue them in BFS.

Java templates

Adjacency list

List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) {
    graph.add(new ArrayList<>());
}
graph.get(from).add(to);
graph.get(to).add(from); // only if undirected

An adjacency list uses O(V + E) space and is usually best for sparse interview graphs. Be explicit about whether every edge is one-way (directed) or added in both directions (undirected).

DFS

void dfs(int node, List<List<Integer>> graph,
         boolean[] visited) {
    visited[node] = true;
    for (int neighbour : graph.get(node)) {
        if (!visited[neighbour]) {
            dfs(neighbour, graph, visited);
        }
    }
}

Time O(V + E). The recursive call means “visit everything reachable from this neighbour.” In a tree, you do not need a visited set if each node has one parent; in a graph, it prevents infinite loops.

BFS shortest path

Queue<Integer> queue = new ArrayDeque<>();
queue.offer(start);
visited[start] = true;
int distance = 0;

while (!queue.isEmpty()) {
    for (int size = queue.size(); size > 0; size--) {
        int node = queue.poll();
        if (node == target) return distance;
        for (int next : graph.get(node)) {
            if (!visited[next]) {
                visited[next] = true;
                queue.offer(next);
            }
        }
    }
    distance++;
}

The outer loop represents one distance layer. The first time BFS reaches the target is the fewest-edge path. Mark nodes visited when enqueuing them, otherwise several parents can add the same node.
