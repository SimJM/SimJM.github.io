String problems

Turn text into a sequence of characters, then choose the pattern that preserves the property you need.

Strings are immutable in Java. Read characters with charAt or toCharArray; use StringBuilder when constructing or repeatedly changing text.

Common imports: 
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

String, Character, and StringBuilder are in java.lang, so they need no import.

Recognise the pattern

Counts or matching characters

Use a frequency array for a known small alphabet, such as lowercase English letters. Use a HashMap for general characters or Unicode-like input.

Contiguous substring

Use a sliding window. State what must remain true in the current substring, then move the left pointer until it is valid again.

Comparison from both ends

Use two pointers for palindromes and similar symmetry checks. Decide whether case and punctuation should be ignored before coding.

Build or reverse a string

Use StringBuilder; repeated + concatenation can repeatedly copy a growing string and become inefficient.

Java templates

Character count

Frequency array

int[] count = new int[26];
for (char ch : s.toCharArray()) {
    count[ch - 'a']++;
}

Use only when the input is guaranteed to be lowercase a–z. The index expression converts each character to a value from 0 to 25. Time O(n); extra space O(1).

Anagram

Compare character counts

public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;
        count[t.charAt(i) - 'a']--;
    }

    for (int value : count) {
        if (value != 0) return false;
    }
    return true;
}

Increment for the first string and decrement for the second. All counts must return to zero. For broader character sets, replace the array with a HashMap<Character, Integer>.

Two pointers

Valid palindrome

public boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;

    while (left < right) {
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        if (Character.toLowerCase(s.charAt(left))
                != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

The inner loops skip characters outside the problem's comparison rules. Each pointer only moves inward, so time is O(n) and extra space is O(1).

Sliding window

Longest substring without repeats

public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastSeen = new HashMap<>();
    int left = 0, best = 0;

    for (int right = 0; right < s.length(); right++) {
        char ch = s.charAt(right);
        if (lastSeen.containsKey(ch)) {
            left = Math.max(left, lastSeen.get(ch) + 1);
        }
        lastSeen.put(ch, right);
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Invariant: the window from left to right contains no repeated character. Math.max prevents left from moving backwards when a duplicate occurred before the current window. Time O(n).

Build text

Reverse words

String[] words = s.trim().split("\\s+");
StringBuilder result = new StringBuilder();

for (int i = words.length - 1; i >= 0; i--) {
    if (result.length() > 0) result.append(' ');
    result.append(words[i]);
}
return result.toString();

trim() removes surrounding whitespace and split("\\s+") treats consecutive whitespace as one separator. The escaped backslash is required because the regex is inside a Java string literal.

Java string reminders

  • s.length() gives the character count; arrays use array.length.
  • Use s.equals(t) to compare string contents—not ==.
  • substring(start, end) includes start and excludes end.
  • Use Character.isLetterOrDigit, Character.toLowerCase, and Character.isWhitespace instead of manual ASCII checks when the requirements allow general text.

Practice

  1. Valid Anagram: compare frequency counts.
  2. Valid Palindrome: clarify whether non-alphanumeric characters and case matter.
  3. Longest Substring Without Repeating Characters: state the sliding-window invariant.
  4. Group Anagrams: choose a stable key: sorted characters or a frequency signature.
  5. Minimum Window Substring: track counts still needed and shrink only when the window is valid.
