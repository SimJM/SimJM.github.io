Sliding window

Solve contiguous array and substring problems by moving each boundary forward at most once.

← Data structures & algorithms

Sliding window is a pattern for contiguous data: subarrays and substrings. It is very common in string questions, but the same idea works for arrays, such as maximum sum over a fixed number of values.

Imports for the string templates: 
import java.util.HashMap;
import java.util.Map;

For simple lowercase English letters, an int[26] frequency array is often faster and simpler than a map.

When should I use it?

Use it

Contiguous range

Look for “subarray,” “substring,” “consecutive,” “longest,” “shortest,” “at most,” or “exactly k.” These often mean a moving left/right boundary can avoid recomputing work.

Fixed window

Window length is given

Examples: maximum sum of a subarray of size k, or count anagrams in every substring of length k. Add the new right value and remove the old left value.

Variable window

Window length is discovered

Examples: longest substring without repeats or minimum substring containing required characters. Expand right; shrink left only when the window violates or already satisfies the condition.

The invariant

Say what is true inside the current window

The invariant is the rule your window maintains. For example:

  • “The current substring contains no repeated character.”
  • “The current window contains at most k distinct characters.”
  • “The current window contains all required characters.”

Explain this rule before coding. It tells the interviewer exactly when to move left, and prevents random pointer movement.

Fixed-size window

Maximum sum of a subarray of size k

public int maxSumOfSizeK(int[] nums, int k) {
    int sum = 0;
    int best = Integer.MIN_VALUE;

    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];           // include the new value

        if (right >= k) {
            sum -= nums[right - k];   // remove the value leaving the window
        }
        if (right >= k - 1) {
            best = Math.max(best, sum);
        }
    }
    return best;
}

Once right ≥ k - 1, sum represents exactly k elements. Each number is added once and removed once: time O(n), extra space O(1). Clarify how to handle k ≤ 0 or k > nums.length if the prompt does not guarantee valid input.

Variable-size windows

Longest substring without repeating characters

public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastSeen = new HashMap<>();
    int left = 0;
    int best = 0;

    for (int right = 0; right < s.length(); right++) {
        char ch = s.charAt(right);
        if (lastSeen.containsKey(ch)) {
            left = Math.max(left, lastSeen.get(ch) + 1);
        }
        lastSeen.put(ch, right);
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Invariant: s[left..right] has no repeated character. The map stores each character’s latest index. Use Math.max so an earlier duplicate never moves left backwards. Time O(n), space O(min(n, alphabet size)).

Longest substring with at most k distinct characters

public int lengthOfLongestSubstringKDistinct(String s, int k) {
    Map<Character, Integer> count = new HashMap<>();
    int left = 0;
    int best = 0;

    for (int right = 0; right < s.length(); right++) {
        char added = s.charAt(right);
        count.put(added, count.getOrDefault(added, 0) + 1);

        while (count.size() > k) {
            char removed = s.charAt(left++);
            count.put(removed, count.get(removed) - 1);
            if (count.get(removed) == 0) count.remove(removed);
        }
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Invariant: the window has at most k distinct characters. Expand first; then repeatedly shrink while invalid. Removing a key at count zero is essential, because count.size() measures distinct characters.

Minimum-window pattern

Shortest valid window

// 1. Add s.charAt(right) to the window count.
// 2. When all required counts are satisfied:
//    - record this window if it is the shortest so far;
//    - remove s.charAt(left) and increment left;
//    - keep shrinking while the window remains valid.
// 3. Repeat for every right pointer position.

For “longest valid” problems, shrink only while the window is invalid. For “shortest valid” problems, shrink while it is valid after recording the answer. That distinction is the source of many sliding-window mistakes.

Common mistakes

  • Using sliding window for a non-contiguous subsequence problem.
  • Moving left without updating the count, sum, or other window state.
  • Forgetting to remove a map key after its frequency becomes zero.
  • Updating the answer before the window has the required size or validity.
  • Calling the approach O(n²): both pointers only move forward, so the usual total work is O(n).

Practice

  1. Maximum Average Subarray I: fixed-size numeric window.
  2. Permutation in String: fixed-size character-count window.
  3. Longest Repeating Character Replacement: variable window with a frequency maximum.
  4. Minimum Window Substring: shortest valid variable window.
  5. Subarrays With K Different Integers: use “at most k” minus “at most k - 1.”
