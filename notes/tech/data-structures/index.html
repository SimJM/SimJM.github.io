Core structures

Fast lookup

Hash map / set

Use for membership, counts, grouping, and complements. Average insert and lookup are O(1). A map stores key-value pairs; a set stores unique values.

Ordered data

Array, linked list, stack, queue

Arrays offer O(1) indexed access but insertions in the middle cost O(n). Linked lists trade direct access for cheap local insertions. Stacks are LIFO; queues are FIFO.

Prioritised work

Heap and tree

A heap gives efficient min/max retrieval: insert and remove are O(log n). A balanced binary-search tree keeps ordered data and supports lookup, insert, and delete in O(log n).

Recognise the pattern

Question language is a clue

“pair / sorted array” → two pointers “contiguous subarray / substring” → sliding window or prefix sum “top k / next smallest” → heap “all combinations” → backtracking “minimum steps / repeated choice” → BFS or dynamic programming

Patterns are not shortcuts around reasoning. State the invariant: for a sliding window, for example, identify exactly what stays true as the window expands and shrinks.

Graphs, recursion, and DP

Traversal first, optimisation second

Use BFS for shortest paths in an unweighted graph because it explores by distance layers. Use DFS for reachability, connected components, cycle detection, and backtracking. Dynamic programming applies when subproblems overlap and an optimal answer can be built from smaller answers.

BFS template 1. Put the start node in a queue and mark it visited. 2. Remove a node; inspect each unvisited neighbour. 3. Mark and enqueue those neighbours. 4. The first time you reach a target is its shortest edge-count path.

Practice questions

  1. Group Anagrams: choose a stable key for every word and analyse the cost of constructing it.
  2. Number of Islands: model the grid as a graph. Compare DFS recursion with an explicit stack.
  3. Kth Largest Element: compare sorting with a size-k min-heap.
  4. Coin Change: define the DP state, base case, recurrence, and answer location.
