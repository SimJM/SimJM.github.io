Core structures

Fast lookup

Hash map / set

Use for membership, counts, grouping, and complements. Average insert and lookup are O(1). A map stores key-value pairs; a set stores unique values.

In Java, reach for HashMap and HashSet. Use TreeMap or TreeSet when you need ordered values and can accept O(log n) operations.

Ordered data

Array, linked list, stack, queue

Arrays offer O(1) indexed access but insertions in the middle cost O(n). Linked lists trade direct access for cheap local insertions. Stacks are LIFO; queues are FIFO.

Use ArrayDeque for both stacks and queues in Java; avoid the legacy Stack class.

Prioritised work

Heap and tree

A heap gives efficient min/max retrieval: insert and remove are O(log n). A balanced binary-search tree keeps ordered data and supports lookup, insert, and delete in O(log n).

Java's PriorityQueue is a min-heap by default. Use Comparator.reverseOrder() when you need a max-heap.

Recognise the pattern

Question language is a clue

“pair / sorted array”             → two pointers
“contiguous subarray / substring” → sliding window or prefix sum
“top k / next smallest”           → heap
“all combinations”                → backtracking
“minimum steps / repeated choice” → BFS or dynamic programming

Patterns are not shortcuts around reasoning. State the invariant: for a sliding window, explain exactly what remains true as the window expands and shrinks.

Counting

Frequency map

Use getOrDefault to count characters, numbers, or objects without special-case branching.

Map<Character, Integer> count = new HashMap<>();
for (char ch : s.toCharArray()) {
    count.put(ch, count.getOrDefault(ch, 0) + 1);
}
Complement lookup

Two Sum

public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> indexByValue = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (indexByValue.containsKey(complement)) {
            return new int[] {indexByValue.get(complement), i};
        }
        indexByValue.put(nums[i], i);
    }
    return new int[0];
}

Check the complement before storing the current value, so the same element is not used twice. The map stores value → earlier index; each lookup and insert is O(1) on average. Overall time is O(n) and space is O(n).

Stack

Valid Parentheses

Deque<Character> stack = new ArrayDeque<>();

for (char ch : s.toCharArray()) {
    if (ch == '(' || ch == '[' || ch == '{') {
        stack.push(ch);
    } else {
        if (stack.isEmpty()) return false;
        char open = stack.pop();
        if (ch == ')' && open != '(') return false;
        if (ch == ']' && open != '[') return false;
        if (ch == '}' && open != '{') return false;
    }
}
return stack.isEmpty();

Invariant: the stack holds unmatched opening brackets in the order they must be closed. A closing bracket must match the stack's top value. This uses O(n) time and, in the worst case, O(n) space.

Sorted input

Two pointers

int left = 0;
int right = nums.length - 1;

while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return true;
    if (sum < target) left++;
    else right--;
}
return false;

For a sorted array, moving left increases the sum and moving right decreases it. That monotonic behaviour proves no candidate pair is skipped. The scan is O(n); include an extra O(n log n) cost if you must sort first.

Contiguous range

Sliding window

Map<Character, Integer> lastSeen = new HashMap<>();
int left = 0;
int best = 0;

for (int right = 0; right < s.length(); right++) {
    char ch = s.charAt(right);
    if (lastSeen.containsKey(ch)) {
        left = Math.max(left, lastSeen.get(ch) + 1);
    }
    lastSeen.put(ch, right);
    best = Math.max(best, right - left + 1);
}

This finds the longest substring without repeated characters. The invariant is that s[left..right] has no duplicate character. Use Math.max when moving left so it never moves backwards after seeing an older duplicate. Time O(n), space O(min(n, alphabet size)).

Top k

Size-k min-heap

PriorityQueue<Integer> minHeap = new PriorityQueue<>();

for (int num : nums) {
    minHeap.offer(num);
    if (minHeap.size() > k) {
        minHeap.poll();
    }
}
return minHeap.peek();

Keep only the largest k values seen so far to find the kth largest. The heap's smallest value is therefore the kth largest overall. Time O(n log k), space O(k). For a max-heap, create new PriorityQueue<>(Comparator.reverseOrder()).

Graphs, recursion, and DP

Traversal first, optimisation second

Use BFS for shortest paths in an unweighted graph because it explores by distance layers. Use DFS for reachability, connected components, cycle detection, and backtracking. Dynamic programming applies when subproblems overlap and an optimal answer can be built from smaller answers.

Queue<Integer> queue = new ArrayDeque<>();
boolean[] visited = new boolean[graph.size()];
queue.offer(start);
visited[start] = true;

while (!queue.isEmpty()) {
    int node = queue.poll();
    for (int neighbour : graph.get(node)) {
        if (!visited[neighbour]) {
            visited[neighbour] = true;
            queue.offer(neighbour);
        }
    }
}

For BFS, mark a node visited when enqueuing it, not when dequeuing it. This prevents duplicate queue entries. A graph traversal takes O(V + E) time.

Dynamic programming

Coin Change

int[] dp = new int[amount + 1];
Arrays.fill(dp, amount + 1);
dp[0] = 0;

for (int current = 1; current <= amount; current++) {
    for (int coin : coins) {
        if (coin <= current) {
            dp[current] = Math.min(
                dp[current], dp[current - coin] + 1
            );
        }
    }
}
return dp[amount] == amount + 1 ? -1 : dp[amount];

State: dp[current] is the fewest coins needed for current. Base case: dp[0] = 0. Transition: try every coin that can be the final coin, then add one to the best answer for the remaining amount. The initial value amount + 1 marks unreachable states safely. Time O(amount × coins.length); space O(amount).

LRU cache

Core idea

Least recently used eviction

An LRU cache has a fixed capacity. When full, it removes the item that has not been accessed for the longest time. Every successful get and every put makes that item the most recently used.

The interview goal is usually O(1) average time for both get(key) and put(key, value).

Data structures

Hash map + doubly linked list

A HashMap<Integer, Node> finds a node by key in average O(1). A doubly linked list moves a known node to the front and removes the least-recent node from the back in O(1).

Keep the most recently used node beside a dummy head, and the least recently used node beside a dummy tail. Dummy nodes remove empty-list edge cases.

Java implementation

import java.util.HashMap;
import java.util.Map;

class LRUCache {
    private class Node {
        int key;
        int value;
        Node prev;
        Node next;

        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> cache = new HashMap<>();
    private final Node head = new Node(0, 0); // most-recent side
    private final Node tail = new Node(0, 0); // least-recent side

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = cache.get(key);
        if (node == null) return -1;
        moveToFront(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = cache.get(key);

        if (node != null) {
            node.value = value;
            moveToFront(node);
            return;
        }

        Node added = new Node(key, value);
        cache.put(key, added);
        addToFront(added);

        if (cache.size() > capacity) {
            Node leastRecent = removeLast();
            cache.remove(leastRecent.key);
        }
    }

    private void moveToFront(Node node) {
        remove(node);
        addToFront(node);
    }

    private void addToFront(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private Node removeLast() {
        Node node = tail.prev;
        remove(node);
        return node;
    }
}

Invariants: the map contains every real list node; nodes are ordered from most recent after head to least recent before tail; dummy nodes are never added to the map or evicted.

Complexity: get and put are average O(1). Space is O(capacity).

Interview explanation: “The map gives me direct access to a key’s node. The doubly linked list lets me move that node to the most-recent position, or remove the least-recent node, without scanning the cache. Each operation changes only a constant number of pointers.”
